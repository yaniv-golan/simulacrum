# F5 player-owned browser-agent assessment protocol

Use a player with their own browser agent. Record the participant identifier, prior exposure, running application's displayed build identifier, browser and agent versions, and the machine used. Prepare a machine with a failure whose cause is independently known to the assessor; do not reveal that cause to the player or agent.

While remaining in the game, the player asks their agent why the machine is not working. Preserve the question, tool interactions and answer. Pass requires an actionable answer that correctly identifies the independently known cause and a repair available through the player's ordinary interface. Verify the suggested repair on the machine. Record whether the player left the game or received assessor help; either invalidates this assessment. Do not substitute an engine-internal diagnostic or an agent controlled by the assessor.
