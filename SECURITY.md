# Security policy

Do not open a public issue for a suspected vulnerability. Use
[GitHub private vulnerability reporting](https://github.com/yaniv-golan/simulacrum/security/advisories/new).
Include affected versions, reproduction steps, impact, and mitigation.

The scripting boundary, blueprint parser, worker watchdog, and dependency supply chain are security-sensitive. During the experimental 0.x line, only the latest released version is supported.
